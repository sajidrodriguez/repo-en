## What I solve

I build complete products: interface, authentication, persistence, integrations,
analytics, deployment and maintenance. The goal is to sustain a product the
business can use, beyond delivering an individual feature.

Mobilec project status refers to my employment there, which has ended;
it does not imply that I currently maintain those systems.

## Selected implementations

### Jit De Flou · private productivity app · production

Jit De Flou's first productivity app went live on **October 1, 2026**.
My contribution covers product development and operation. Access, code and data
are private and are not exposed in this presentation.

The [public demo](https://jitdeflou.com/demo-app?lang=en) is available. It starts
blank, without fictional data, and does not provide access to the private app.

### Mobilec corporate website · production

An application built with React, Next.js and TypeScript. It brings together the
public website and lead capture with a corporate dashboard connected to Google
Analytics, session authentication and tools for administration and sales.
An extension for technical support was planned when my employment ended.
I used Tailwind CSS to build the interface.

Firebase App Hosting deployments were triggered by pushes to the GitHub
repository. A scheduled GitHub Actions workflow updated news weekly with
Gemini: editorial automation running alongside deployment.

### AI conversational assistant + secure integration layer · production

Two coordinated applications divide responsibilities between the conversational
experience and operational integration. They were designed, built and maintained
end to end by a single developer.

### Jit De Flou · public website and services

The [Jit De Flou website](https://jitdeflou.com) is operational.
It connects services, a virtual agent and human support. Its commercial journey
is described in [Growth interfaces](./growth-interfaces.md).

## Product principles

- Design for real use, beyond the demonstration.
- Keep clear boundaries between interface, data and integration.
- Make relevant states observable without turning the dashboard into the
  entire product.
- Treat maintenance, security and deployment as part of the product.

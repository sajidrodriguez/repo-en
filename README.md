## Selected case · Mobilec

At Mobilec, I designed and built a coordinated ecosystem connecting
conversational support with a secure integration layer. It connects data,
operations and telemetry with human teams and physical devices, without
placing every responsibility in a single application.

```text
customer channels
        ↓
conversational orchestration
        ↓
secure middleware
        ↓
data · operations · telemetry
        ↓
human teams + physical devices
```

This deliberately abstract view illustrates design decisions without exposing
proprietary code, customer data or sensitive operational topology.

## Technologies in context

- **AI conversational assistant and secure integration layer:** JavaScript/TypeScript and Node.js for services and integrations; PostgreSQL for data; Redis/BullMQ for queues and background processing; AWS EC2 for operations.
- **Mobilec corporate website:** React, Next.js and TypeScript for the website and dashboard; Google Analytics for analytics; Firebase App Hosting for deployments linked to GitHub.
- **Editorial automation for Mobilec's corporate website:** GitHub Actions ran weekly news updates with Gemini.
